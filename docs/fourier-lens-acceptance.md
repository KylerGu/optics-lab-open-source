# 傅里叶变换场景

二维布局沿用现有高斯聚焦与圆孔场景：左侧调参数，中间显示前焦面输入、透镜和后焦面频谱的光路，右侧显示二维频谱屏和读数。曲线、符号解释与模型条件默认折叠。条纹周期 d、光束半径 w、焦距 f 支持图中拖动，频谱屏观察点支持拖动改变 xF；滑杆、数值输入、撤销/重做和本机保存联动。

## 模型与物理量

输入为二维高斯包络调制的余弦振幅条纹：

U(x,y) = exp[-(x²+y²)/w²] · [1 + m cos(2πx/d)] / (1+m)。

前后焦面距透镜均为 f，采用相干单色、理想无限透镜的近轴标量傅里叶模型。先变换光场振幅，再取模平方，并以当前频谱中心光强归一化；未对输入光强直接变换。νx=xF/(λf)，νy=yF/(λf)。在yF=0的剖面，频谱振幅是位于0与±λf/d的三个高斯分量相干叠加。每个分量的1/e²光强半径 wF=λf/(πw)。完整二维频谱再乘y方向的高斯振幅。

λ使用nm，f、d、w使用mm，xF、x₁和wF使用μm；ν₀=1/d使用mm⁻¹。m为振幅调制度，m=0时没有周期条纹或一级分量，周期不再影响图样，相关输入与定位按钮停用。w与wF均为半径，不是直径。标注可分别开关λ、d、w、m、f、xF、ν₀、x₁、wF及I/I₀。

图中横向尺度用于展示；光线说明频率到位置的映射，不代替完整波动传播计算。输入用振幅灰度显示，频谱屏为真实二维光强的平方根显示以看清较弱分量，曲线与读数保留真实归一化光强。忽略有限透镜截断、像差、偏振与离焦，不包含4f空间滤波。

参考：[TU Delft，前后焦面傅里叶变换与振幅光栅三峰频谱](https://qiweb.tudelft.nl/aoi/coherentimaging/coherentimaging/)。

## 器材复制与助手

条纹与无条纹均复制四个现有器件：高斯光源、余弦振幅光栅、理想透镜和频谱屏。保留波长、周期、束腰半径、调制度、焦距及观察位置；光源束腰位于输入面，输入到透镜、透镜到屏均为 f。搭建页从实际器件识别共轴前后焦面条件，独立计算二维频谱与有限圆屏收集功率。频谱相对光强以本次频谱中心 I₀ 为基准，图样采用平方根提亮。移动、转动或缩小器材导致计算条件失效时撤去频谱，不沿用旧结果。

AI沿用场景助手，接入真实计算、参数修改、参数比较和零级/正一级/负一级定位。定位仅修改观察位置，保留其他参数；无条纹时拒绝定位一级。助手答复默认简短，比较表使用真实数值。
