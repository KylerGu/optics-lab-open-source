# 两镜谐振腔稳定性验收

入口：仿真场景库 → 激光光学 → 两镜谐振腔稳定性；地址 `#/scene/resonators-0`。本轮只完成这一场景。

## 物理模型

空气中的理想球面或平面两镜腔，小角度高斯基模。第一镜固定在 z = 0，第二镜位于 L。朝腔内的凹面镜曲率半径为正，凸面镜为负；平面镜的倒曲率为零。忽略口径截断、增益、损耗和热透镜，稳定性不代表激光已起振。

采用 g₁ = 1 − L/R₁、g₂ = 1 − L/R₂。严格稳定区为 0 < g₁g₂ < 1；边界和不稳定腔不显示有限稳定高斯包络。共焦腔 R₁ = R₂ = L 的往返矩阵为 −I，单凭往返条件不能唯一确定光束，界面明确选取 z₀ = L/2、zR = L/2 的对称高斯解。

普通稳定腔：Dg = g₁ + g₂ − 2g₁g₂；z₀ = Lg₂(1 − g₁)/Dg；zR = L√[g₁g₂(1 − g₁g₂)]/|Dg|；w₀² = λzR/π。主图只画 0 ≤ z ≤ L 的实际包络，半径采用中心光强 1/e² 的定义。腔外束腰不画腔内束腰点或半径，腔外观察面不显示腔内光斑。

默认值：532 nm、L = 300 mm、两面凹镜曲率半径均为 500 mm，观察位置 150 mm。g₁ = g₂ = 0.4，乘积 0.16；束腰位于 150 mm，半径约 0.197 mm，两镜处半径约 0.2354 mm。

“调到稳定”仅改变 L，按稳定区间的真实边界分段检查，从可调镜距 10–2000 mm 内选择一个严格稳定区间的内部值。无可用区间则禁用；不更改镜曲率、镜类型、波长或观察位置。

依据：[RP Photonics — Stability Zones of Optical Resonators](https://www.rp-photonics.com/stability_zones_of_optical_resonators.html)、[RP Photonics — Resonator Modes](https://www.rp-photonics.com/resonator_modes.html)。束腰公式另以完整往返矩阵及两镜波前匹配独立核对。

## 页面与操作

- 沿用扩束场景的宽屏布局、左右可收起和调整宽度的面板。恢复默认固定左下角，结果固定右侧，保留底部“横纵比例不同”。
- 第二镜和观察面可拖动或方向键微调；第一镜作为位置基准固定，计算出的束腰不能独立拖动。拖动期间视图固定，整次拖动一次撤销/重做。
- 直接点击几何量中文名称切换标注，不添加独立开关。波长和稳定参数保留普通读数。曲率半径只有腔镜和真实曲率中心都在视野中时才提供图中标注；半径尺寸线需要光轴及端点均可见，不用画框边缘代替物理端点。
- 右侧稳定区域图显示当前真实 g₁、g₂；超出范围时不把点钉在图框边缘。束腰、两镜半径和观察光斑使用同一参数计算。
- 相关公式仅有顶部一个入口，包括稳定性、高斯基模、平凹与共焦腔。独立计算器支持稳定乘积、束腰半径、观察半径、稳定镜距；隐藏的旧输入不约束其他目标，试算不更改场景。

## 验证

新增前端 5 项、后端 4 项验证。13 组参数覆盖普通稳定腔、平凹腔、共焦、临界、不稳定、双凸镜、凸凹镜、腔外束腰、腔外观察面及参数范围边界。独立构造 K₁ P K₂ P 往返矩阵，核对行列式、迹、光束往返自洽及两镜波前曲率；前端与后台读数一致，无有限模式时返回空值而非无穷数。

实际 Chromium 浏览器核对通过：几何量显隐、临界不画假光束、共焦分支、平面镜隐藏曲率输入、调到稳定、拖动与一次撤销、缩放和平移、键盘微调、面板收放和调整宽度、刷新保存、目录搜索和入口、公式排版及试算。2560×1220、1440×900、1024×768 无横向溢出，恢复默认按钮可见。页面控制台只有开发提示；服务重启时的短暂连接失败与场景无关。

真实既有模型服务调用通过：

- 只调整镜距到稳定：1200 mm → 750 mm，其他六项参数不变，计算证据与最终场景一致。助手撤销和场景重做通过。
- 比较 300、500、1000 mm：分别为稳定、共焦（简并）、临界，生成三组真实计算结果并保留当前 750 mm 镜距。
- 后端验证只读比较、目标预览、否定调参和无解请求不能改动场景。
