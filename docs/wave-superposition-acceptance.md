## 物理范围

均匀介质中的两束同频、同向、同偏振、完全相干的平面光波：

- `E1 = A1 cos(2πz/λ)`；`E2 = A2 cos(2πz/λ + Δφ)`，合成电场逐点相加。
- 振幅使用同一相对电场基准；相对平均光强以单位振幅单束光为1，故 `Irel = A²`，不是当前瞬时电场平方。
- 输入波长 nm、位置 μm；内部统一单位。显示固定参考时刻的电场快照，已移除动画、播放按钮与时间滑杆；旧动画草稿保留五个光学参数并移除时间相位。
- 同向同频模型中的平均光强不随观察位置变化；不产生双缝空间条纹。不包含拍频、部分相干和偏振差异。
- 等振幅反相时合成振幅、电场、平均光强均为零，此时合成初相位不定义；不等振幅反相时残余振幅为两束振幅之差的绝对值。

公式库和场景浮窗共用三张知识卡：电场叠加、合成振幅、平均相对光强。场景当前参数填入求解器，试算不修改主场景；反求相位差返回可达范围内的解，零振幅退化条件拒绝唯一反求。公式参考：[OpenStax — Interference of Waves](https://openstax.org/books/university-physics-volume-1/pages/16-5-interference-of-waves)。
