# 非球面和实体柱面透镜（2026-10-05）

“添加器材 → 透镜”新增两个入口：非球面透镜提供平凸、平凹；柱面透镜提供平凸、平凹实体。会聚、发散作为卡片行为提示。六种球面和三种教学理想卡片保留；旧装置不自动换类型。用户本轮明确暂不添加消色差组合透镜。

## 曲面、尺寸和材料

四种类型为 `aspheric-convex-lens`、`aspheric-concave-lens`、`plano-convex-cylinder-lens`、`plano-concave-cylinder-lens`。前顶点位于局部光轴−t/2，后顶点+t/2；前曲后平，改变器件朝向可让平面先迎光。默认口径或宽高25 mm、中心厚5 mm、曲面顶点半径50 mm、材料N-BK7。

非球面为旋转对称圆形实体。标准偶次非球面矢高使用 z(r)=c·r²/[1+√(1−(1+k)c²r²)]+A4·r⁴+A6·r⁶，c为有符号顶点曲率；平凸正、平凹负。圆锥常数k默认−1；k=0且A4=A6=0退化为球面，k=−1且两项为0为抛物面。A4、A6单位分别mm⁻³、mm⁻⁵，在“高阶曲面修正”中编辑，保留小系数显示和存储精度。

实体柱面沿局部U方向为圆弧，沿V方向不弯曲；截面沿高度挤出形成矩形实体。宽度对应U、高度对应V，均可独立编辑。聚焦方向角旋转真实曲面和宽高方向，屏的U/V读数按屏自身方向测量，线焦点核对时需同时对齐屏参考方向。

前后端均检查整个口径的曲面定义域、边缘厚度至少0.1 mm，以及凸凹曲率保持一致。高阶修正采用保守的解析曲率下界，不能保证全口径凸凹一致的参数会明确拒绝；当前不支持曲率反转、双面非球面、自由曲面或柱面非球面。自定义玻璃沿用587.56 nm参考折射率和阿贝数的色散近似。

## 真实光路与支持范围

圆锥面/柱面解析求交；带A4/A6的曲面在有限实体范围内先确定唯一导数驻点，再分段求根，不用显示网格近似折射。前后表面按实际交点和曲面倾斜折射，并使用入射光源波长的材料折射率。无镀膜表面有偏振相关透射损耗，内部全反射保留，实体侧边吸收光线。普通表面反射产生的杂散支路不追踪。

587.56 nm参考有效焦距为1/[(n−1)c]，后焦距为有效焦距−t/n；高阶系数不改变轴心小角度焦距，但会改变边缘光线的聚焦。柱面参考焦距仅对应弯曲方向。网页不开放虚构的“直接修改焦距”；应改曲率、材料或厚度，并以实际追迹确定屏位置。

显示网格、三维辅助线、真实光路、参数校验和Agent采用相同曲面。两类实体暂不支持高斯包络、衍射和干涉；高斯输入经过实体后只显示几何采样，并说明限制。原理想薄透镜及原场景的计算保持原模型。

Agent已接入查询、选择、添加、材料/曲面/尺寸/方向修改、追迹、参数扫描和目标核对。新字段及焦距依据也接入网页独立验证；无效修改不部分应用，旧参数文件补无害默认值。

## 验收证据

全量118项前端检查、239项后端检查和生产打包通过。新增物理核对包括：球面退化一致、独立费马等光程解、带高阶项的交点及法线、斜入射和接近横向的双交点、光路可逆、柱面旋转后单方向聚焦/发散、矩形边界吸收、任意三维朝向、材料色散、旧模型兼容、保存恢复、Agent原子修改及扫描。

独立非球面参考为n=1.5、R=50 mm、k=−n²=−2.25、A4=A6=0，平面先迎光；不同入射高度的平行光满足费马等光程关系并聚到同一点。该核对没有以本实现的交点函数作为标准答案。

实际配置的AI模型从空装置搭建非球面与实体柱面两条独立光路并追迹、扫描和最终复算。587.56 nm，每路1 mW：非球面输入半径8 mm，屏半径约7.16×10⁻¹⁵ mm（几何模型的浮点数误差），功率0.921584 mW；柱面输入半径2 mm、方向角30°，屏U半径0.001491 mm、V半径1.986213 mm，功率0.921613 mW。非球面k从−2.25扫描到0，在同一屏的半径变化0.238458 mm。六项目标通过，实际模型返回通过前端独立验证。理想几何点焦点不代表实际光束可无限小。

浏览器逐个添加四种卡片，编辑非球面k、A4、A6及柱面宽高、厚度和方向，保存、导出和刷新恢复；确认1×10⁻⁹的A6未被显示或存储为0。导入实际Agent光路后成功计算、显示实体透镜和双路光斑。原浏览器草稿与存档在验收后恢复。检查图片和计算记录保存在忽略目录 `output/`。
