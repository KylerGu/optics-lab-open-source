# 点光源照度与距离验收记录

入口：仿真场景库 → 照明与探测 → 点光源照度与距离；直接地址 `#/scene/radiometric-quantities-0`。

沿用现有场景的浅色三栏界面：左侧公式、光强 I 和距离 r，中央二维点光源与接收面，右侧照度 E 随距离的曲线。两侧可拉伸与收起；支持全屏、自动保存、撤销重做、相关公式浮窗及场景 AI。点击“光强”“距离”“照度”独立切换图中对应字母与数值标注，不增加无对应位置的物理量。

拖动接收面时数值、曲线当前点及示意明暗同步变化；整段拖动作为一次撤销。接收面支持方向键，Shift 加大步长，Home/End 到达边界。右侧可切换线性与对数纵轴，对数轴明确说明每格相差10倍；光源关闭时自动使用包含零的线性刻度。

## 物理范围

本轮按已讨论的照度版本实现，原待开放卡片“点光源辐照度与距离”改为“点光源照度与距离”，保留入口身份。采用 `E = I / r²`，I 为沿接收方向的发光强度（cd），r 为距离（m），E 为照度（lx）。不混用辐射强度（W/sr）、辐照度（W/m²）或光功率（W）。参考：[NIST — Realization of the candela](https://www.nist.gov/pml/sensor-science/optical-radiation/realization-candela)。

只计算理想点光源对接收面中心的垂直入射照度；不计算整个接收面的照度分布。真实光源尺寸应远小于距离，不含环境光、介质吸收、遮挡和反射。图中光线与接收面颜色仅作示意。

AI 使用同一后台计算结果解释、比较和调参。比较保持参数；目标反求只改变距离，保持光强。目标必须为正且可达；光源关闭或目标超出范围时拒绝应用。修改可撤销，等待时的手动修改不会被旧回复覆盖。未提供“复制到光路搭建”。
