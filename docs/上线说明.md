# 这一版上线到 Render

网页、物理计算和 AI 助手由同一个服务提供。无需评委安装软件或配置模型接口。

1. 将项目代码放入自己的私有 GitHub 仓库。不要上传 `.env`、`output` 或个人文件。
2. 登录 Render，创建 Web Service，选择该仓库，运行环境选 Docker，实例选 Free。
3. 在服务的 Environment 中填写 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`。沿用本机模型配置即可；密钥只放在后台环境变量中。
4. 健康检查地址填写 `/api/health`，开始部署。成功后 Render 提供 `https://…onrender.com` 网址。
5. 用网址检查：打开场景、运行三维仿真、给 AI 助手发送一句问题。三项均正常后再分享给评委。

也可以用仓库中的 `render.yaml` 创建 Blueprint；三个 AI 配置项需要在平台填写。

免费服务闲置 15 分钟会休眠，下次打开可能需要约一分钟启动。先用于试运行；正式评审前再决定是否升级。AI 模型调用仍使用你的额度。

上线后继续在本机修改，提交并推送到同一个仓库，Render 会重新部署，网址保持不变。参赛提交时保留对应版本。

研究记录和装置存档仍保存在访问者自己的浏览器里，不会自动从本机网址迁移到线上网址；可用已有导出、导入功能转移装置。

本机验证上线模式：先运行 `npm run build`，再运行 `python -m backend.web`，打开 `http://127.0.0.1:10000`。

参考：[Render Docker 部署](https://render.com/docs/docker)、[免费服务限制](https://render.com/docs/free)。
