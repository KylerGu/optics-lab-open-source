# 球差与色差的拖动交互

本场景按用户要求仅保留直接拖动，不提供自动播放、暂停或沿光线移动的光点。

- 沿光轴拖动观察屏，立即更新出射光线的终点、屏上几何光线落点和光斑半径。
- 上下拖动透镜边缘，改变通光直径；中心厚度仍由曲率、口径及边缘厚度共同决定，沿用原场景物理模型。
- 曲率半径仅使用左侧已有参数控件调整，移除光路图内重复的曲率滑杆。图中的观察屏和口径拖动控件也支持方向键、Home和End。
- 一键切换单色球差和红绿蓝三色，显示450、550、650 nm的近轴焦点及对应后焦距。
- 结果区保留结果名称、数值、单位和图形，移除每项结果下方的说明、结果侧栏中的说明段落和图底部文字。其他场景的说明保留。

焦点圆点与文字仍通过引线对应，近轴焦点用蓝色、边缘焦点用棕色。屏位于焦点前方时，实际光线在屏上终止；屏后虚线表示移开屏后的光路参考，悬停虚线可查看说明。虚线不参与屏上光斑或功率计算。屏移到所有近轴焦点后方时自动隐藏参考线。

拖动期间固定坐标范围，避免控件因自动缩放而脱离鼠标。每次松手只形成一次可撤销的参数修改；保留重做、参数范围检查、自动保存和刷新恢复。

新增浏览器端即时计算，使用与后台一致的两个球面交点和折射定律。每一帧的图形、读数、趋势和屏上落点来自同一参数状态，不依赖网络响应。后台继续作为独立核对和AI操作的计算依据。未新增真实玻璃数据库、反射损耗或衍射模型；材料仍采用场景原来的教学色散式。

结果名称后统一显示物理符号：折射率 n、中心厚度 t、有效焦距 F、后焦距 BFL、边缘光线焦距 Lₘ、纵向球差 Δz（下标 SA）、红蓝焦距差 Δz（下标 RB）、几何均方根半径 r（下标 RMS）。公式、参数和图中使用相同符号；Lₘ、SA、RB 的下标含义是本场景明确说明的约定。

默认图只增加口径 D 与屏距 s 的尺寸线。屏距尺寸线跟随透镜、观察屏和实际光路的下沿，留出28像素间距，不再固定于图框底部；选中其他距离时避开其标注。点击结果名称后，仅显示这一项的图形标注，再点一次隐藏；标注沿用读数颜色。折射率标在透镜内部；厚度从前顶点量到后顶点；有效焦距从后主面 H′ 量到近轴焦点，BFL 从后顶点量到同一焦点，两者不能共用起点。球差尺寸线连接边缘与近轴焦点，红蓝差连接450与650 nm近轴焦点，距离均来自当前计算结果。

点击 r（下标 RMS）会打开右侧光线落点图，显示真实统计半径的圆与半径线；这不是最外圈落点或光斑边界。各项符号定义收进“相关公式”的折叠内容，不恢复结果下方或主图底部说明。选择标注不改变物理参数、色彩模式或撤销记录，拖动期间标注同步更新。

单色球差模式不显示红蓝近轴焦距差读数或对应图形标注；三色模式才显示。由工具栏、侧栏、预设或撤销切回单色时，清除已选中的红蓝标注，之后切回三色也不自动恢复它。底层保留透镜在两种参考波长下的计算，不把单色实验的比较量误写成零，也不改变其他读数和光路。

此前验证覆盖41组边界及随机配置，逐项比较浏览器与Python后台的光路、焦距、几何光斑、趋势和读数；另独立核对球面交点、折射角、上下对称、近轴极限、拖动范围及球差和色差趋势。本次补充独立后主面位置、实际测量端点、零色散时零跨度，以及单色/三色不同屏距下的落点统计半径验证，不改变物理模型。

浏览器核对八项符号与标注切换、点击不改变读数、光斑标注自动打开、观察屏和口径的真实鼠标拖动与撤销、侧栏曲率调节、公式排版及1024像素窗口显示；不存在播放控件或移动光点，结果和主图底部说明保持移除。
