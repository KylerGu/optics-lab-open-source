# 高斯光束透镜聚焦验收

本轮只完成单片理想薄透镜聚焦。入口：场景库 → 激光光学 → 高斯光束透镜聚焦；可直接打开 `#/gaussian-focus`。

## 模型与结果

- 空气、理想基模高斯光束 M² = 1、小角度、无像差薄透镜。半径采用光强降至中心 1/e² 的约定。
- 使用 `q₋ = zᴸ − z₀ + i zR`、`1/q₊ = 1/q₋ − 1/f` 求出出射束腰和光斑。考虑透镜处的波前曲率。
- 默认参数：λ = 532 nm，w₀ = 0.5 mm，z₀ = 0 mm，f = 100 mm，zᴸ = 200 mm，z = 320 mm。
- 默认结果：出射束腰位置约 300.457 mm，束腰半径约 0.033790741 mm，观察光斑半径约 0.103605569 mm。
- 透镜前方的出射束腰明确标为反向延拓；紫色虚线表示延拓光束，实际入射包络保持独立。此时透镜后实际最小半径在透镜处。
- 观察位置在透镜前时读取入射光束；近平行状态说明取透镜后 100 mm 内半径变化小于 1%。远处束腰有视野外提示及定位按钮。
- 公式参考：[Edmund Optics — Propagation of a Gaussian Beam Through a Thin Lens](https://www.edmundoptics.co.uk/knowledge-center/application-notes/lasers/gaussian-beam-propagation/)，其中复光束参数与薄透镜变换关系用于模型依据。

## 计算核对

`src/gaussianFocus.test.ts` 包含 5 项验证：8 组参数与 Python 独立复数计算核对；透镜两侧半径连续；实际束腰、延拓束腰和近平行状态；平移不改变光斑大小；复制与撤销重做。

复制出的三维装置由现有后端实际计算，观察光斑半径为 0.10360556916974709 mm，与独立 ABCD 矩阵算式一致。复制保留波长、束腰半径及位置、透镜位置及焦距、观察位置。搭建器不能表达的输入或口径条件会禁用复制，原因放在按钮提示内。
