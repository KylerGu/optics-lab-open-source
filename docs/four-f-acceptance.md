# 4f 系统与空间滤波

左侧参数、中间二维光路、右侧观察屏沿用傅里叶场景样式。观察屏可切换输出、滤后频谱和输入；曲线与模型说明默认折叠。滤波全宽 a、偏移 c、两镜共同焦距 f、输入周期 d、光束半径 w 支持图中拖动，输出观察点支持拖动 x′。中文物理量开关对应字母标注；保存、撤销重做与现有 AI 助手联动。

## 物理模型

相干单色光、理想无限薄透镜、两镜等焦距 f。输入到第一镜 f，镜间 2f，第二镜到输出 f；滤波片固定在两镜公共焦面。全通成等大小倒像，本例对称输入看起来相同。输入与前一场景一致：

Uin(x,y)=exp[-(x²+y²)/w²]·[1+m cos(2πx/d)]/(1+m)。

令 ν=xF/(λf)，输入沿 x 的频谱是中心位于 0、±1/d 的三个高斯振幅分量。通光狭缝的 H 在 c−a/2≤xF≤c+a/2 内为1，外为0；遮光挡片取其补函数，全通为1。a为**全宽**，c从中心量起，均使用μm；w为1/e²光强半径，使用mm。

滤波作用于复振幅，第二镜再作傅里叶变换：Uout(x′)=∫A(ν)H(λfν)exp(−i2πνx′)dν。数值计算保留实部和虚部，最后取模平方，另一方向仍是高斯包络。居中狭缝为横向低通，居中挡片为横向高通；偏心狭缝选择一段频率。滤波半带宽νc=a/(2λf)，偏移时其中心为c/(λf)，不把偏心滤波称为居中截止频率。

输出读数与输入共用 Iin(0) 亮度基准，滤波后不单独归一化。透过功率比 T 是完整无限平面的光强积分比，使用三个高斯分量平方的交叉项计算；它不是单点光强。观察屏用光强平方根提亮，曲线与读数保留真实光强。光路为示意，虚线表示被滤波片挡住的分量；不作为波动计算依据。

参考：[TU Delft，相干4f成像与频谱面光瞳](https://qiweb.tudelft.nl/aoi/coherentimaging/coherentimaging/)，第7.2节。忽略有限镜片截断、像差、偏振和离焦；本场景演示一维振幅滤波，不支持任意上传图片或二维圆孔滤波。

## 助手与复制

AI复用现有配置，支持解释、真实计算、只读参数比较和滤波目标。低通、高通与选一级只修改滤波方式、位置和宽度，保留输入与焦距、观察点；无条纹时拒绝选一级。修改可整轮撤销。

所有滤波方式均可复制当前参数：高斯光源束腰放在输入余弦振幅光栅，周期 d 与调制度 m 保留；两片透镜等焦距，输入/镜间/输出间距为 f、2f、f；公共焦面复制宽度 a、位置 c 以及通光/遮光方式，全通移去滤波片；输出屏保留观察点 x′。通常6个器件，全通5个。

搭建页从实际器件推导参数，不回放保存的场景图。只在单高斯源、余弦振幅光栅、两理想等焦距透镜、单输出屏及可选单滤波片，共轴 f/2f/f 间距，束腰位于输入面，w=.5至2mm、f=80至130mm、d=80至400μm、λ=380至780nm、a=10至5000μm、|c|≤2200μm，且输入光栅和镜片口径覆盖至少六束腰半径时提供4f波动输出。滤波片高度须覆盖六个焦面高斯半径。移离焦面、倾斜、改距、缩口径或加其他器件时清除波动结果并提示；保留几何追迹。

相干输出用缩放复互补误差函数解析积分，独立频谱积分核对；保持 I/Iin(0) 基准。T 是完整平面比值，输入功率从高斯源扣除振幅光栅损耗；有限圆屏到屏功率另按二维强度积分，不能用无限平面 T 冒充有限屏收集比例。3D 屏纹理与放大的结果观察屏使用同一输出，标注平方根提亮。默认矩形光栅、普通狭缝及旧存档的行为保持兼容。AI器件编辑支持新模式和参数，工具提供4f波动读数及目标核对，扫描保留完整实际器件快照。
