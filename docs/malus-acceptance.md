# 偏振片与马吕斯定律

沿用三栏界面、面板宽度调整、全屏、自动保存、撤销重做、公式浮窗和场景 AI。左侧仅入射功率 Pin、入射偏振方向 α、透光轴 β 三项参数，中间为沿光传播方向观察的偏振片正视图，右侧为透射功率、透过比例、夹角以及功率随夹角变化的小曲线与一行公式。

拖动蓝色或紫色的两端圆点，直接旋转入射偏振方向或透光轴，两个参数独立，整次拖动一次撤销。中文名称切换对应 α、β、θ 的角弧与数值。各物理量文字、数字、滑杆及对应图形配色一致，开关标注不隐藏物理轴线。窄屏标注位置限制在画布内，图形居中。模型条件为两句、默认收起，无图内滑杆和额外参数列表。

## 计算与复制

固定光斑面积的线偏振平行光正入射单片理想偏振片，轴向透过率1，垂直电场分量完全阻挡。θ是两条无向轴的较小夹角0–90°，不等于入射角；方向相差180°等效。Pout=Pin cos²θ，T=cos²θ。正交时输出精确为0，输入功率为0时输出为0，T仍表示器件由角度决定的透射比例。忽略反射、有限消光比与器件截光，不含未偏振光。默认10 mW、α=0°、β=45°，输出5 mW，透过比例50%。

复制为线偏振平行光源、理想偏振片和功率计，保持源功率、源偏振方向、偏振片透光轴角度，口径保证光束完整通过；功率计量程100 mW，包含场景全部功率范围。使用现有搭建器的偏振计算，不新增偏振器材。复制后为独立装置，可继续修改或保存，不改回场景参数。

AI使用真实计算程序读取和比较参数。最大透射、消光、半功率及指定功率目标仅调整透光轴，保留入射功率及偏振方向；指定目标超过入射功率或零源无法唯一确定角度时拒绝。比较不修改参数。

## 验证

前端211项、后台351项检查通过。新增验证用独立电场向量投影核对功率，64组功率与角度组合核对前端、后台及完整器件副本的功率计读数；覆盖零功率、平行、正交、180°方向等效、公式反求退化条件、API参数检查及AI修改权限。

实际浏览器核对两轴拖动实时更新、输入功率保持、整次撤销、三个中文标注开关、颜色对应、平行/半透/正交预设、无效输入与恢复默认、公式上下标与求解、保存刷新；检查2048、1440、1024及390像素窗口宽度，无横向页面溢出。复制12 mW、α=20°、β=80°后，真实搭建计算及原场景都给出3 mW。实际配置的AI完成只读角度比较及仅调透光轴到6 mW，源功率和偏振方向保持，应用与撤销通过。
