# 六种实体球面透镜

“添加器材 → 透镜 → 球面透镜”提供平凸、双凸、平凹、双凹、正弯月、负弯月。卡片绘制对应截面；会聚、发散是行为提示。旧会聚/发散/柱面薄透镜列入“教学理想模型”，旧文件和场景不自动转换。新增非球面和实体柱面见[对应说明](aspheric-cylindrical-lenses.md)；消色差组合透镜未加入。

## 几何和材料

前四种独立类型为 `plano-convex-lens`、`biconvex-lens`、`plano-concave-lens`、`biconcave-lens`。长度为 mm。新增可选字段 `frontRadiusMm`、`backRadiusMm`、`centerThicknessMm`；半径存正的大小，曲率正负由形状确定。平凸/平凹前面是曲面、后面是平面；后表面半径不参与计算，也不开放编辑或Agent扫描。改变朝向可将平面转到入射侧。

默认口径25、中心厚度5；平凸/平凹曲面半径50，双凸/双凹两面半径100，材料N-BK7。前后顶点位于局部光轴−t/2和+t/2，器件位置是两顶点的中点。渲染、构建辅助线和后端追迹使用相同截面及曲面法线。

半径必须大于半口径，边缘厚度至少0.1。无效几何在导入、网页修改、后端请求、Agent修改与扫描时均拒绝；Agent失败修改不部分应用。N-BK7沿用Sellmeier色散公式，自定义玻璃由587.56 nm参考折射率与阿贝数拟合二项Cauchy近似。阿贝数表示不同颜色折射率的差异大小。

正弯月 `positive-meniscus-lens` 默认前半径50、后半径100；负弯月 `negative-meniscus-lens` 默认前100、后50。两者前凸后凹，沿局部正光轴的有符号半径均为正，两半径均可调整。正弯月要求前半径小于后半径，负弯月要求前半径大于后半径，并根据厚度和材料核对参考光焦度保持为负。无效调整不会悄悄改变类型；网页和Agent明确提示原因。旧六种参数文件均按对应类型补默认值。

## 真实追迹和参考焦距

求交前后表面和有限侧边，在实际交点按Snell定律折射，即按表面朝向和两侧折射率求新方向。每个光源使用自身波长的材料折射率。内部全反射保留偏振复电场和功率；无镀膜表面计算菲涅耳透射损耗，非全反射的杂散反射支路不追踪，未抛光侧边吸收光线。

沿局部正光轴传播时，有符号半径分别为：平凸(+R1,∞)、双凸(+R1,−R2)、平凹(−R1,∞)、双凹(−R1,+R2)。表面光焦度P1=(n−1)/R1，P2=(1−n)/R2，平面项为0。厚透镜光焦度P=P1+P2−t·P1·P2/n，有效焦距EFL=1/P，后焦距BFL=(1−t·P1/n)/P。

网页显示587.56 nm参考EFL/BFL和边缘厚度；零光焦度显示∞。BFL从局部后表面顶点起量，EFL从后主平面起量。参考焦距用于小角度估计；不同波长和入射高度会改变聚焦位置，可观察几何球差。实际屏位置以追迹为准。

球面透镜暂不传播高斯包络，不计算衍射、干涉、镀膜或一般波动传播。高斯光源通过后显示几何光线，并提示包络限制。旧 `lens` 和 `cylindrical-lens` 的薄透镜定律、焦距参数、已有场景和高斯计算保留。

## Agent与验收

器材查询、类型选择、添加、修改材料/曲率、三维瞄准、逐面追迹、扫描和核对全部接入。新增 `lens_focal_mm` / `lens_back_focal_mm` 判据；网页从形状独立重新计算，拒绝不符读数。新球面透镜不允许把旧 `focalLengthMm` 作为调焦字段。

新增检查覆盖四种形状、小角度厚透镜公式、会聚/发散、两面透射损耗、光路可逆、翻转后的球差、任意三维朝向、色散、侧边吸收、全反射、零光焦度、无效几何/API拒绝、Agent事务修改/扫描、旧高斯模型、几何与辅助线一致性、保存恢复和Agent结果校验。全量通过102项前端检查、223项后端检查及生产打包。

实际配置的模型从空装置设计平凸聚焦光路，调用查询、搭建、计算、扫描和最终复算：参考EFL=100 mm；587.56 nm、输入半径0.1 mm、输入3 mW时，屏采样半径0.000003449 mm、功率2.7648 mW。扫描曲面半径50至80 mm，同一屏半径变化0.037494 mm。四项目标全部通过，返回也通过前端校验。

浏览器逐个添加四种透镜，修改双凸半径/厚度/材料/朝向，保存、导出、刷新恢复，再导入含四种透镜的三路光路并渲染。分类、参数、实际透射光线与探测结果正常。检查图片和计算记录在忽略目录 `output/playwright/`；结束后恢复原浏览器存档。
