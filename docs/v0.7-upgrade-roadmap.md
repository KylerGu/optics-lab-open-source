## 二、 Phase 1（`feat/darkroom-and-hud`）详细技术实施方案

### 目标定位
将三维光路画布从“白底工程线条图”升级为**物理级光学暗室实验室（Optical Darkroom）**，并把原来藏在底部抽屉里的探测器读数转化为**随参数拖动实时跳动的科研级光斑分析仪 HUD**。

---

### 子模块 1A：三维光学暗室模式（Optical Darkroom & Breadboard）

- **涉及文件**：
  - `src/SpatialBench.tsx`
  - `src/spatialGrid.ts`
  - `src/BuilderWorkspace.tsx`
  - `src/builder.css`（及必要时的 `src/builder-readability.css`）
- **核心设计**：
  1. **开关入口与持久化**：
     - 在 `BuilderWorkspace.tsx` 画布右下角 `.sb-display-controls`（网格显示、光线显示按钮旁）新增「暗室模式」切换按钮（支持快捷键或 `aria-pressed` 状态，持久化至 `localStorage('optics-builder-darkroom-v1')`；默认开启或按约定提供一键切换）。
  2. **光学面包板无限网格升级（`src/spatialGrid.ts`）**：
     - 扩展 `createInfiniteGrid()` 的 `ShaderMaterial` uniforms，新增 `darkroom`（`0.0` / `1.0`）。
     - 在暗室模式下，地面呈现低反光深炭灰阳极氧化平台质感，叠加微光 `25 mm` 光学平台标准螺孔点阵与 `100 mm` 主分度刻度线，保持远距离抗锯齿平滑衰减，避免视觉噪点。
  3. **暗室环境光与玻璃器件轮廓质感（`src/SpatialBench.tsx`）**：
     - 暗室开启时：`renderer.setClearColor` 切换为深邃暗室底色（如 `#090d16`）；`s.floor.material` 切换为深沉阳极氧化平台色调（如 `#0f1623`）；
     - 重新平衡暗室三点布光：压低环境漫反射（`HemisphereLight`），保持并微调轮廓边缘光（`instrument-rim`）与金属/玻璃高光反射（`environmentIntensity`），让玻璃透镜与棱镜在暗场中呈现清晰透亮的边缘轮廓；
     - 在 `s.scene.fog` 启用时（如显微镜渲染态），同步适配暗室雾效背景色。
  4. **暗室 UI 浮层高对比度适配（`src/builder.css`）**：
     - 当容器处于暗室状态（如 `.sb-viewport.is-darkroom`）时，画布内的器件编号悬浮标签（`.sb-build-labels > button`）、左上角计算状态徽章（`.sb-canvas-status`）、左下角视角切换条（`.sb-view-controls`）、右下角显示控制条（`.sb-display-controls`）以及失光提示条（`.sb-light-hint`）统一切换为深色半透明毛玻璃样式，确保文字、选中高亮态与三维坐标轴（`X / Y / Z`）在暗底上清晰可读。

### 子模块 1B：物理级激光辉光与丁达尔高斯体积光束（Additive Laser Glow & Gaussian Beam Shader）

- **涉及文件**：
  - `src/spatialBeamShader.ts`（新建）
  - `src/SpatialBench.tsx`
- **核心设计**：
  1. **主光线双层加法混色辉光（Core + Corona Halo）**：
     - 在暗室模式或渲染态（`rendered`）下，利用 `THREE.AdditiveBlending`（加法混色）为高能量激光主光线与传播路径叠加双层发光结构：
       - 内芯层：随局部功率提升向高亮白芯过渡；
       - 外晕层：保留波长对应真实单色光色相的柔和光晕，解决白底减法混色下激光显得像普通彩线的痛点。
  2. **高斯光束连续体积光强着色器（`src/spatialBeamShader.ts`）**：
     - 替代 `SpatialBench.tsx` 中原本单调的 `MeshBasicMaterial` 均匀半透明管状网格。
     - 为每段高斯光束几何体传入截面局部半径分布与束腰参考信息，在自定义 Vertex / Fragment Shader 中：
       - **径向高斯分布**：利用视角法线夹角与径向位置近似柱体积分光强，呈现中心明亮、边缘按高斯包络柔和消散的丁达尔体积光雾感；
       - **轴向能量密度守恒**：根据局部光斑半径相对于最小束腰半径的缩放比 $(w_{\min} / w(z))$ 动态强化焦点/束腰处的光强亮度与白芯饱和度，让学生直观看到“光束在束腰处能量高度集中、离开瑞利长度后迅速散暗”的物理现象；
       - **零后处理开销**：纯着色器叠加 `AdditiveBlending` + `depthWrite: false`，不引入全屏多 Pass RenderTarget 性能负担，保持拖动滑块与 Gizmo 旋转时的流畅帧率。

### 子模块 1C：画布右上角常驻「实时科学光斑分析仪 HUD（Live CCD Beam Profiler）」

- **涉及文件**：
  - `src/SpatialBeamProfilerHud.tsx`（新建）
  - `src/spatialBeamProfiler.ts`（新建纯计算与渲染辅助模块，便于单元测试）
  - `src/spatialBeamProfiler.test.ts`（新建单元测试）
  - `src/BuilderWorkspace.tsx`
  - `src/builder.css`
- **核心设计**：
  1. **轻量常驻悬浮仪器窗（HUD）**：
     - 固定浮在三维画布右上角（支持一键折叠为紧凑状态徽章与展开完整仪器面板），在无需打开底部大型「仿真结果」抽屉的情况下，边拖动透镜/光阑边实时观测探测器光场变化。
  2. **多探测器智能选择**：
     - 扫描 `experiment.elements` 中全部探测器（`screen`、`power-meter`、`sensor`）与 `result.screens` / `result.imaging` / `result.diffraction` / `result.fourF` / `result.fourier`：
       - 若当前选中器件是探测器，优先跟随展示该探测器；
       - 否则自动优先选择正在接收有效光斑/功率的探测器，并提供顶部紧凑标签切换多个探测器。
  3. **三种科研级实时可视化视图**：
     - **二维伪彩光强热力图（2D False-Color CCD Map）**：
       - 基于 Canvas 2D 实时合成探测器截面二维光强矩阵：
         - 高斯光斑：$I(u,v)$（支持柱面镜导致的各向异性椭圆光斑 `sampledRadiusUMm` / `sampledRadiusVMm`）；
         - 几何光斑：有限口径覆盖轮廓与中心采样落点；
         - 衍射/相干条纹：结合 `result.diffraction`、`result.fourier`、`result.fourF` 的一维/二维分布映射为条纹或频谱光斑；
         - 成像传感器：展示合焦锐度与离焦弥散圆（`focused` / `defocusMm`）。
       - 支持 **Inferno 科研伪彩** 与 **真实波长单色光** 两种配色模式切换，并叠加十字基准线与 $1/e^2$ 包络标尺环。
     - **双轴正交截面光强曲线（U / V Cross-Section Profiles）**：
       - 紧贴热力图上方与右侧绘制水平（U）与垂直（V）轴向的实时光强截面包络曲线，拖动透镜过焦点时可清晰看到波峰骤然变尖、峰值飙升的实时动态。
     - **核心指标与偏振椭圆角标**：
       - 底部紧凑显示关键数值：到屏功率（mW）、$1/e^2$ 半径或几何半径（mm）、波长（nm）；当光路包含偏振器件且存在 `polarizationStokes` 时，同步渲染动态斯托克斯偏振椭圆与偏振态标签（线偏振 / 圆偏振 / 椭圆偏振 / 未偏振）。
