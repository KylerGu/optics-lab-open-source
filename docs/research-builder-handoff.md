# 科研工作区调用光路搭建 Agent

科研工作区可以按研究需要调用已有三维搭建 Agent。现有装置够用时继续使用，不要求每轮重新搭建。用户直接描述研究目标即可，不需要跳转页面才能开始计算。

例如：“我想研究透镜焦距如何影响观察屏上的光斑。请设计所需光路，再把焦距从 80 到 120 mm 取 5 点比较，其他参数固定。请说明使用的模型和限制。”

## 基本流程

1. 科研 Agent 读取已有对象，判断是否需要新结构；缺少关键研究条件时澄清。
2. 如需新装置，调用现有搭建 Agent。从空装置设计，或在指定原对象的副本上设计。
3. 搭建 Agent 按目标搭建、追迹和核验；交接前再次独立复算目标。失败、不完整、无目标或追迹达到上限的方案不加入研究。
4. 通过后新增一个“Agent 生成装置”，设为当前对象，并保留原装置。科研 Agent 在同一轮使用新对象继续仿真、扫描或其他受支持的研究工具。
5. 对象、搭建目标、核验依据及实际计算记录保存到研究记录。刷新后可继续研究；点击装置名称仍可在搭建页面查看副本。

## 范围

- 每轮最多尝试生成一个装置，一项研究最多保留六个对象。一次搭建委托内部仍可使用搭建 Agent 原有的修正流程。
- 不修改原对象、已有搭建草稿或搭建存档，不自动导出文件。
- 搭建失败明确说明原因，不默认使用原对象的结果冒充新装置。停止或不完整交接不新增对象。
- 装置核验通过后，若后续模型请求失败或时间不足，保留已核验对象与实际记录，明确后续研究尚未完成。
- 沿用已有器件、计算模型、工具适用条件和证据解释限制；核验通过仅表示模型内目标达标，不代表实测或整个研究结论已验证。

## 检查

后端连接测试使用模拟模型回复驱动实际搭建 Agent 和科研 Agent，并运行真实追迹、参数比较及独立核验。覆盖从零生成、基于原装置生成、折转结构、失败、取消、数量与时间限制、后续请求失败及生成对象的再次请求。

前端检查交接数据的完整性、原对象参数保留、核验依据、同轮计算、历史恢复和后续请求。页面检查使用后端生成的真实计算记录模拟接口回复，不访问真实模型服务。
