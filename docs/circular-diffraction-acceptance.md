# 圆孔衍射与艾里斑

参照已有高斯聚焦与薄透镜成像场景，中间显示简洁二维光路：平行光、圆孔侧视、观察透镜与焦平面。观察屏圆环移入右侧结果面板，移除立体台面、器件旋钮与屏面弹窗。可拖圆孔上下边缘改 D、拖焦平面改 f，右侧观察屏可拖动观察点；圆孔到透镜间隔固定，透镜到屏的距离始终等于 f。焦平面横向位置按 f 线性映射；拖动支持指针捕获、边界限制、方向键与一次拖动一次撤销。径向光强曲线默认折叠。八个物理量名称分别开关 λ、D、f、r、dₐ、r₁、θ、I/I₀ 标注。参数支持撤销、重做、本机保存、中央亮斑和第一暗环定位、屏面缩放及适配图样。

## 物理范围

均匀单色平行光通过圆孔与理想观察透镜，屏位于后焦平面。使用近轴标量衍射：u=πDr/(λf)，I/I₀=[2J₁(u)/u]²；中央极限为1。D为圆孔直径，f为透镜焦距，r为焦平面半径；输入波长用nm、孔径和焦距用mm、观察半径用μm，计算统一单位。

首个零点u₁=3.8317059702075125，r₁=(u₁/π)λf/D，艾里斑直径dₐ=2r₁。公式显示1.22，计算使用1.21966989。艾里斑直径不是半高宽；归一化光强不是总功率。角度由atan(r/f)计算。忽略像差、离焦、偏振和有限观察透镜截断；没有两点分辨率仿真。

圆环颜色适当提亮用于看清旁瓣；读数和曲线保持真实相对光强。装置和角度示意放大；焦平面图样按微米标尺绘制。参考：[TU Delft 标量衍射，焦平面艾里图样公式447](https://interactivetextbooks.tudelft.nl/interactive-optics/content/Chap6_Diffraction/DiffractiveOptics_2022_01Clean.html)、[NIST DLMF 10.9 贝塞尔函数积分](https://dlmf.nist.gov/10.9)。
