# 激光阈值与增益验收

## 模型

假定已有可以共振的单模，均匀增益介质填满两镜之间的长度 L。小信号增益 g₀ 和内部损耗 α 都是光强系数，单位 m⁻¹；输入长度 mm、反射率百分数，计算分别换为 m、0–1。输出镜不吸收，透射率为 1 − R₂。

小信号往返倍率 Q₀ = R₁R₂ exp[2(g₀ − α)L]，阈值增益 gth = α + ln(1/(R₁R₂))/(2L)。严格超过阈值时，在等效均匀饱和模型 g(I) = g₀/(1 + I/Iₛ) 下，稳态 I/Iₛ = g₀/gth − 1，饱和增益被钳位在 gth；相对出射光强 Iout/Iₛ = (1 − R₂)I/Iₛ。有损腔低于或恰好达到阈值时取零稳态受激光强，忽略自发辐射；此时增益不强行钳位，仍为 g₀。

I 是输出镜前的等效腔内光强，Iₛ 采用同一有效约定。相对输出不是瓦数；本场景不推断未给定的材料、光斑面积、泵浦转换效率或绝对功率。均匀光强近似不适合精确预测高单程增益器件；不计算瞬态、多模竞争、空间烧孔、几何稳定性或模式相位。

两镜均全反射且内部损耗为零时，gth = 0，模型不确定唯一有限稳态光强；光强读数为空，不画正常输出曲线。输出镜全反射但有其他损耗时，允许有限腔内光强，出射光强为零。

默认 L = 100 mm、g₀ = 2 m⁻¹、α = 0.2 m⁻¹、R₁ = 99%、R₂ = 90%、试算 I/Iₛ = 0.5。阈值约 0.7770542576 m⁻¹；小信号往返倍率约 1.2771，稳态 I/Iₛ 约 1.5738，出射 Iout/Iₛ 约 0.1574。

“调到阈值”和“调到阈值以上”仅改变 g₀；后者取 1.2gth。理想无损或超出可调增益上限 50 m⁻¹ 时禁用目标。试算光强仅控制饱和曲线采样，不修改自动计算的激光稳态。

依据：[RP Photonics — Laser Threshold](https://www.rp-photonics.com/laser_threshold.html)、[RP Photonics — Gain Saturation](https://www.rp-photonics.com/gain_saturation.html)。阈值公式另以两次单程传播和两镜反射独立核对。
