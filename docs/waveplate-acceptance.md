# 波片与偏振态

左侧波片类型、入射功率、偏振方向、快轴角；中间居中放置三维波片、入射电场与输出电场，拖端点改变两个方向角，拖空白旋转视角，支持缩放和复位视角；右侧偏振态、输出功率、相位延迟、长轴方向、短长轴比、固定正视旋向与同步的偏振正视图。斯托克斯分量收在折叠项内。保持三栏、可调面板、全屏、AI、公式、独立保存及撤销重做。

颜色固定对应物理量；输入偏振为蓝色、快轴为紫色、输出电场为绿色，参数名、数字、角弧、轴线与图例一致。默认只显示α和β；ψ仅在输出有固定长轴时可点击显示。相位延迟和功率不在图内制造滑杆。动画可暂停；使用归一化电场，明确慢放。中间曲线连接同一时刻各位置的电场端点，不是传播光路；光沿直轴传播。右侧仅显示固定输出截面的轨迹，与三维输出截面使用同一时刻。空间长度为示意，振幅归一化。

## 模型

线偏振输入，固定532 nm设计波长，理想无损波片；四分之一波片δ=π/2、半波片δ=π。基底 f=(cosβ,sinβ)、s=(−sinβ,cosβ)，输出复场 f cos(α−β)+s sin(α−β)exp(iδ)。时间约定exp(−iωt)，端点坐标为Re(E)cosφ+Im(E)sinφ。

S₁=|Ex|²−|Ey|²，S₂=2Re(Ex Ey共轭)，S₃=2Im(Ex Ey共轭)，与搭建页功率计U/V基底一致。理想完全偏振光满足S₁²+S₂²+S₃²=1。短长轴比使用稳定表达式|S₃|/(1+sqrt(S₁²+S₂²))，避免线偏振附近的浮点误差误判为椭圆偏振。ψ=atan2(S₂,S₁)/2，模180°；圆偏振无唯一ψ。零功率时不显示输出电场和偏振曲线，偏振量为空。右侧固定观察方式下S₃>0顺时针，S₃<0逆时针；不使用约定易混淆的左右旋命名。

半波片保留线偏振、输出方向ψ=(2β−α)模180°；四分之一波片输入与快轴成45°时圆偏振，沿任一主轴时线偏振，其余通常椭圆。输出功率等于输入功率，忽略吸收、色散、倾斜入射和截光。本场景不接受未偏振或椭圆偏振输入。

复制当前线偏振光源、当前类型的波片和功率计到光路搭建。两处使用相同532nm设计波长、输入角与快轴角，全部光束在器件口径内；复制副本保留原场景，沿用独立草稿与搭建编辑流程。

AI可以真实计算、只读比较及调参。目标circular只能用于四分之一波片；direction只能用于半波片；linear对准快轴。目标均只改变快轴，不偷换波片、源方向或功率；零功率与器件不匹配时拒绝目标。公式卡使用真实S₃计算，正确显示α、β、δ及下标，不提供多解角度的伪唯一反求。

## 验证

- 前端4项针对本场景的验证：独立半波片角度、四分之一波片轴比、功率守恒、场轨迹旋向、输入边界、历史和公式联动；160组参数核对前后端及完整器材复制的功率与S₁/S₂/S₃。
- 后台3项验证：独立物理边界、API与公式、AI只读和字段保持。初版全量前端215项、后台354项通过；三维版另增空间电场传播方向、快轴分量与右侧同步验证，本场景4项通过，生产构建通过。
- 实际浏览器：两个方向拖动和整次撤销、标注开关与计算后的真实颜色、三种预设、波片切换、动画及暂停、零功率、无固定长轴、非法数字与重置、公式计算、刷新保存。2048、1440、1024及390像素宽度无横向溢出，图形中心核对通过。
- 实际复制按钮：Pin=12mW、α=17°、β=62°、四分之一波片；复制后功率计12mW，归一化S₁≈0、S₂≈0、S₃=1，与原场景圆偏振一致。
- 实际已配置AI：只调快轴从30°到62°产生圆偏振，保留四分之一波片、Pin=12mW、α=17°；应用及撤销成功。
- 三维版实际浏览器：两个空间平面上拖角度，整次撤销与重做；空白拖动仅改视角，复位、键盘改角度、标注颜色与开关、同步动画及暂停、波片类型和预设、零功率均通过。2048、1440、1024、390像素宽度无横向溢出，端点均在图内，波片中心与画布中心一致。
