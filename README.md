面向本科生光学学习与实验探究的智能仿真平台。通过自然语言驱动实验设计、光路搭建与物理计算，帮助学生将抽象原理转化为可观察、可操作、可验证的仿真实验。顶部入口为**仿真场景库、公式库、光路搭建、实验探究工作区**。高斯光束属于场景库，打开场景直接进入其交互计算页；自由组合器件和实验探究分别在各自区域完成。

实验探究工作区以光学疑问和仿真实验为中心。左侧切换探究记录，中间提问与继续探索，右侧查看装置和已有计算记录。首页提供“看懂一个现象”“改变参数看看”“设计一个小实验”三个可编辑示例，无需先选择装置即可提问。复杂探究的计划按需生成，从顶部菜单查看；笔记和完整记录也在菜单中导出，空白页不展示空实验记录和重复笔记入口。装置仅显示名称链接，点击在原有光路搭建页打开。

右侧材料栏在宽屏上可拖动分隔线调整宽度，刷新后保留偏好；方向键微调，双击恢复默认宽度。默认正文与装置名称使用14像素字号，长计划和计算条件可以展开，完整文本、进度依据与数据仍保留。窄屏自动改为上下排列。

新探究先显示“未命名探究”；问候不会成为标题，提出明确研究问题后由 Agent 提炼题目。手动改名后不再自动覆盖。以前由问候生成的标题会根据已有研究对话恢复。Agent 获得的计算说明区分公式计算的高斯半径与光线采样的几何范围、功率；有限比较点中的最小值不能直接代表连续范围的最优值。这些解释规则用于后续回答，历史回复保留原文。

按需生成的探究计划逐项显示待开展、已核对、已完成计算、已完成分析或待验证。计算完成必须关联真实结果；沿用历史记录时保留原引用，历史完成依据跨轮保留。扩展计划保留未改变步骤的进度，已完成分析不表示实验验证完成。旧计划没有进度资料时显示“进度未记录”。执行记录保留工具操作依据，不作为学习完成或理解程度的判据。实验记录增加序号、比较器件与范围、点数及光源条件摘要；打开结果可查看计算时的参数与搜索条件，并导出原装置参数。理想模型的理论推导、实际计算点与实测验证分别解释。

通过“选择装置”从“我的装置”“仿真场景库”“导入装置文件”选入对象，每项探究最多保留6个。我的装置包含全部已保存装置和当前草稿；装置选择器目前仅接入高斯自由传播，其余场景暂不能在这里选入。文件支持当前三维装置和早期直线装置的JSON格式，每份最多1 MB。这里读取平台中的装置存档；磁盘文件通过导入选择，不自动扫描本机文件夹。

每个对象选入时保留独立参数，可以“设为当前”供助手分析，或在问题中指定多个对象比较。进入关联光路后，两处延续同一份探究对话；当前光路的手动或助手修改同步到该探究对象，后续交流与计算使用新参数，已有计算记录保留原快照。“更新参数”会显示来源中的变化，确认后只用于后续计算；文件对象通过“重新导入参数”更新。更新或移除对象不会改写历史结果。点击对象名称或推荐方案会将对应副本带入光路搭建，不自动覆盖已保存的装置存档。

实验探究助手按本轮需要回应：问候简短回复，普通提问直接解释，明确的计算和调参指令直接执行；具体表述涉及易混淆关系时才针对性讲清，不凭“为什么”“不懂”等关键词启动教学。要求演示或确实需要计算证据时，选择最简单的合适模型和对照实验，说明改变什么、观察哪里以及结果如何对应原问题。没有固定诊断流程，不强制预测、测验、填表或报告。示范实验可自主选择并标明示范参数；实际装置的定量优化仍需明确关键条件。没有装置时也可运行已支持的独立干涉模型，或按需委托搭建助手生成装置。选择对象后可调用三维仿真、参数比较、多对象读数比较，以及兼容同轴高斯单透镜的聚焦搜索和误差分析。工具不编辑原装置，每份结果保留原参数。图表与原始数据可从对话或右侧实验记录打开，支持 CSV/JSON 导出；整项探究可以导出笔记和完整 JSON。记录自动保存在此浏览器，旧研究记录和手动标题继续保留；只有旧的未命名占位标题自动更新为“未命名探究”。测量数据拟合、文献检索及未实现的光学物理不作为已验证能力。

对话行为可用 `python scripts/validate_inquiry_responses.py --live` 检查，覆盖问候、普通提问、操作指令、概念区分和主动要求演示；会调用本机配置的真实模型并可能产生接口费用。不加 `--live` 只列出案例。每轮请求、原始回复和客观检查结果保存在 `output/inquiry-responses/`，失败也保留；是否多余教学、解释是否准确还需逐条审阅，不能仅凭工具检查通过判定。

讲解可以按需附上“定位器件”“调整参数”“前后对照”入口，第一版支持已有薄透镜和观察屏的位置、薄透镜焦距。点击后复用光路搭建页的器件选中与参数控件，顶部保留相关说明并可返回探究；普通问答不自动跳页。前后对照保留打开时的装置条件，通过原仿真服务计算调整前和当前观察屏的高斯半径，以同一比例并排显示光斑轮廓与读数（非相机图像）。学生自由调参、撤销或关闭；其他条件一同变化时明确提示，缺少有效读数或计算失败时不显示虚构光斑，并可重试。旧讲解与当前装置不一致时拒绝定位，不覆盖新修改；切换装置会关闭对照。画面入口及其装置引用随探究记录保存，临时对照在关闭或离开搭建页后结束。

## 启动

建议使用与部署配置一致的 Node.js 22、Python 3.13。在本目录打开终端，首次运行（Windows PowerShell）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
$env:OPTICS_PYTHON = (Resolve-Path .\.venv\Scripts\python.exe).Path
npm run dev
```

打开[本地实验室](http://127.0.0.1:5173)。这条命令同时运行网页和Python计算服务，保持终端开启即可使用。按Ctrl+C停止。若端口5173或8000被占用，请先关闭占用端口的旧服务。Python代码修改后需重新启动；网页代码修改后自动更新。如果Python安装在特殊位置，可设置 `OPTICS_PYTHON` 为Python程序路径。

```powershell
npm test             # 检查实验数据、编辑历史与计算响应校验
npm run test:physics # 用独立公式和标准案例检查物理计算
npm run build       # 检查类型并生成前端构建文件
```

`npm run build`只生成网页文件。若要运行前后端合一的完整服务，构建后执行 `.\.venv\Scripts\python.exe -m backend.web`，打开 `http://127.0.0.1:10000`。开发模式默认只监听本机；合并服务按 `backend.web` 配置监听全部网络接口，使用时应按部署环境限制访问。

需要 AI 功能时，先将 `.env.example` 复制为 `.env`，填写 `AI_BASE_URL`、`AI_MODEL` 和自己的 `AI_API_KEY`。例如使用 DeepSeek 官方服务时，地址为 `https://api.deepseek.com`，模型按自己可用的服务配置；现有演示使用 `deepseek-flash`。不配置密钥也可使用不依赖 AI 的本地仿真与物理计算。不得将真实密钥写入前端代码或提交到 Git。

上方测试命令中的 Python 应指向已安装依赖的虚拟环境。Windows 可直接运行 `.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -v`；`npm test` 使用 Node.js。Linux/macOS 可用 `python3 -m venv .venv`，安装依赖后执行 `OPTICS_PYTHON="$PWD/.venv/bin/python" npm run dev`；构建后的服务使用 `.venv/bin/python -m backend.web` 启动。

## 已实现

- 偏振控制：偏振片与马吕斯定律。左侧入射功率、偏振方向与透光轴，中间居中的偏振片正视图，右侧透射功率、透过比例、夹角及功率曲线。拖动蓝色、紫色端点直接旋转两个方向；点击中文名称切换同色角度标注。保留自动保存、撤销、公式和场景AI，支持完整复制线偏振光源、偏振片及功率计到光路搭建并保持功率一致。采用正入射理想偏振片，不包含未偏振光或有限消光比。

- 波片与偏振态：切换半波片和四分之一波片，拖动输入偏振方向与快轴；中间居中显示可旋转查看的三维波片与空间电场，拖端点改角度、拖空白转视角，动画可暂停；右侧同步显示输出偏振正视图及偏振态、功率、相位延迟、长轴方向与短长轴比，斯托克斯分量折叠显示；圆偏振无固定长轴，零功率不显示电场。参数与图中标注同色，保留AI、公式、保存和撤销，支持复制源、当前波片与功率计并核对偏振态及功率。工作在固定532nm设计波长，采用理想无损波片与线偏振输入。
- 布儒斯特角与双折射：同一场景切换两个独立二维模型。界面视图拖入射光端点，右侧比较s/p反射率曲线，p光在布儒斯特角处不反射；晶体视图拖光轴，显示o光直行、e光在晶体内走离、两束平行出射以及毫米间距。保留同色标注开关、AI、公式、独立保存和撤销；未提供相应物理器材前不开放复制。边界和验证见 [验收记录](docs/polarization-refraction-acceptance.md)。

- 光纤场景配色：数值孔径与导模、单模光纤耦合的参数名称、数字、滑杆及对应图中标注使用同一颜色；不同几何物理量使用不同颜色，角弧与尺寸线同步配色。

- 光纤与波导：单模光纤耦合。左侧六项参数，中间光束与模场示意，右侧耦合效率、功率和损耗。拖动端面光斑中心、边缘或入射光源调整偏移、光斑大小和倾角；中文名称切换对应几何标注。保留预设、自动保存、撤销、相关公式和场景 AI。采用焦点在端面的高斯光场重叠近似，不计端面反射，模场半径与纤芯半径区分；暂不接入光路搭建。

- 光纤与波导：光纤数值孔径与导模。左侧五项参数，中间简洁的等比例二维光线，右侧结果。图中拖动入射光源或入射线调整角度，参数与结果实时同步，一次撤销恢复整次拖动。折射率、半径和角度可点击中文名称显示对应材料标注、尺寸线或角弧；波长、NA、V 与截止波长只在参数或结果栏显示。支持预设、自动保存及场景AI真实计算、比较与调参。几何导光与弱导近似的单模判据分开；暂不接入光路搭建。

- 照明与探测：照度分布与光源方向。沿用三栏界面，侧视图拖动射灯和方向，俯视图拖动观察点；照度热图、观察线曲线和区域统计同步更新。中文参数名称切换对应字母标注，支持保存、撤销和场景 AI。采用简化定向点光源，半强角表示光强减半处；固定主轴光强，区域统计按网格估算。暂不连接光路搭建。
- 照明与探测：点光源照度与距离。左侧调节光强（cd）与距离（m），中间二维接收面可拖动，右侧照度曲线同步更新。点击“光强”“距离”“照度”切换对应 I、r、E 标注，参数和开关自动保存，拖动可一次撤销。仅计算理想点光源下垂直接收的中心照度（lx），不表示整面分布。场景 AI 可解释、只读比较及保持光强按目标照度反求距离；不能达到时保留参数。暂不复制到光路搭建。


- 默认进入仿真场景库，可按分类和关键词查找当前可用的高斯光束场景。场景卡片的“打开场景”固定进入高斯光束页，不读取旧课节选择，不改写搭建装置。
- 高斯光束页：左侧四个参数滑杆，传播图、观察光斑和数值在拖动过程中逐帧更新；主图自动容纳束腰、一个瑞利长度和观察平面，圆点标记束腰中心。支持直接拖动束腰中心与观察平面、缩放、平移、全屏、一次撤销整段拖动和自动保存。
- 光路搭建：分类选择实验器材，在三维空间中移动、旋转、折转和分光；先用简化器件搭建，再切换器件外观与光路渲染。仿真结果按需打开，不再提供二维原理图和结果与公式入口。
- 光路搭建支持装置标签页：新建、导入、从场景或实验探究区复制、打开存档均保留已有装置；重复打开同一存档会切回原标签。各装置保留独立修改与撤销记录，打开的标签及草稿可在刷新后恢复（撤销记录只保留在本次页面内）。关闭未保存修改时可选择保存并关闭、不保存或取消；保存失败不会关闭装置。画面常显随视角转动的 X/Y/Z 方向提示，选中器件时在移动轴旁显示同色字母。
- AI助手结合当前场景或装置展开、收起，点击发送后才调用AI。场景与搭建装置分别保存，只有点击“复制装置到光路搭建”才把场景参数带入搭建区。
- 高斯光束助教使用独立的自由传播上下文与计算读数，只能读取、调节或比较波长、束腰半径、束腰位置和观察位置；不提供透镜搭建、聚焦设计或误差分析工具。比较保留当前参数，明确要求调参时才生成经核对的修改，可撤销。
- 高斯助教复用本轮计算，核对明确的数值、传播区域与比较范围内的单调趋势声明。正常回复不增加模型请求或重新仿真；发现矛盾时至多重答一次，重答不提供操作工具，仍有矛盾或重答失败时仅返回已计算事实。概念问答保持原流程。核对不覆盖所有自由文字推理，不能视为完整物理正确性保证。
- 浅灰背景、白色面板与蓝色操作按钮，光路占主要空间；高斯光束是库内场景，没有单独的顶部入口。
- 单透镜误差分析：透镜位置允许偏差使用毫米，焦距允许偏差使用百分比；两种偏差同时组合，0表示该参数固定。

“光路搭建”使用独立的三维装置草稿；初次进入为空白空间，旧版直线装置可自动迁移或从 JSON 导入。左侧以“当前装置”为主，点击“添加器材”再打开分类选择窗口。器材按光源、透镜、反射与分光、棱镜、滤光与偏振、光阑与狭缝、观察与探测、支架与平台分类。目前全部 14 种光学器材选项可用，包括直角棱镜、三棱镜、偏振片、狭缝和功率计；支架与平台在渲染时自动显示。选中器件后，左侧显示对应的光学参数，右侧调整 X/Y/Z 位置及水平、俯仰角；支持数值输入与滑杆调整，滑杆松开后计算，整次拖动可以一次撤销。提供聚焦、立体折转与双路分光示例，支持撤销、重做、保存、导入和导出。点击“光路渲染”展开展示空间；点击“运行仿真”按需打开当前观察屏结果，计算说明收在结果面板中。

三维计算由 `/api/spatial/simulate` 完成。空间反射使用向量反射定律，透镜使用局部近轴薄透镜近似，分光镜按照透过率分配功率，光阑可以阻挡采样光线，滤光片按透过率衰减。光源可调整发射功率（0–1000 mW）、波长、半径、发散半角与光线数量（1–201 条，默认 9 条）。几何光束按照设置半角向外展开；高斯光束采用理想基模，发散半角与波长、束腰半径联动。几何采样覆盖圆截面内部与边界，采用面积分布和对称点对，避免光阑实验只有中心光线透过或全透过的两个读数，也避免中心位置偏移。总功率不随光线数量增加；到屏功率仍是有限等权几何采样估计，较低光线数会产生阶梯误差，不能当作精确高斯光场积分。屏上采样范围不等于高斯光斑半径。高斯光源另用复光束参数计算理想包络和光斑半径，场景复制保留原高斯参数及自由传播结果。支架属于外观示意；棱镜支持实体逐面折射、全反射与材料色散，偏振片支持理想电场投影，功率计显示有限探测面的收集功率并检查量程。狭缝支持矩形截光，并在限定条件下独立计算单缝远场归一化条纹；不计算一般波动传播、多光源相干干涉、真实曲面像差或棱镜后的高斯像散。

新器材参数包含棱镜边长、厚度、顶角、轴向转角和材料；BK7 使用随波长变化的折射率，自定义玻璃使用参考折射率及阿贝数近似色散。未镀膜界面计算菲涅耳透射损耗和全反射，不追踪普通反射的杂散分支。偏振片可调透光轴与轴向透过率，光源可选线偏振角或未偏振状态。功率计可调探测面与量程，超量程时不给出有效读数。

狭缝宽度范围 0.001–20 mm，可调高度与轴向转角。单缝条纹仅适用于均匀平行光直接正入射、窄而长的狭缝、无遮挡的正对观察屏以及 `a²/(λL) ≤ 0.1` 的远场条件；强度剖面、第一暗纹和中央亮纹宽度与几何采样功率分开保存和显示，不冒充衍射能量积分、近场计算或高斯入射衍射。AI 能扫描新参数、核对功率计读数、亮纹宽度、单调增加或减少趋势，以及棱镜真实主光线的偏折角。传给模型的曲线记录仅含关键测量量，完整曲线仍保留给网页。载入新装置或重置视角时按器材范围自动取景，较长和较高的光路可完整显示。

物理依据：[SCHOTT N-BK7 数据表](https://media.schott.com/api/public/content/41e799d0bf874807a0bb8e702fbb75b5?v=54856406)的折射率和色散系数；[OpenStax 偏振](https://openstax.org/books/university-physics-volume-3/pages/1-7-polarization)与[单狭缝衍射](https://openstax.org/books/university-physics-volume-3/pages/4-1-single-slit-diffraction)的理想模型。器件是教学与设计用的理想化模型，不是实测标定。

探究与关联光路复用同一个对话界面、发送入口和探究存档，不复制聊天文字。搭建页显示所属探究、当前装置和选中器件；在同一探究的不同装置间切换时沿用对话，但明确本轮操作对象。切换探究不会带入另一项的历史。独立光路的对话与装置存档保持固定关联，刷新或关闭标签后重新打开同一份存档会恢复原对话，不绑定最近一次探究；首次保存会接续当前草稿的对话，普通保存或改名保持关联，“另存为副本”则开始独立的新对话。光路搭建助手不显示对话导出入口，关联探究统一通过实验探究工作区的“下载探究笔记”和“保存探究记录”导出。此前无法确定归属的公共聊天数据仍保留，不自动拼接到某项探究。

关联光路与探究参数不同且不能确认修改来源时，先显示版本选择；一份光路关联多个探究时显示所属探究选择。修改只应用到本轮对应对象；等待回复时手动改参或切到其他光路会拒绝过期修改。同一已有装置支持一条消息内先计算、再修改、再计算，最多委托3次修改；修改前和各次修改后的结果分别保留计算时的参数，刷新和导出后仍可查看。完整结束后只应用最终方案，可一次撤销；失败、超时或步骤未完成时仅保留候选计算，不应用部分修改。新建仍每轮最多一次，与修改分轮执行。光路检查沿用已有物理模型与独立复算，保存装置存档仍由“保存装置”完成。

搭建装置和场景参数分别保存，复制后独立编辑。搭建区由实验探究助手统一交流，三维设计 Agent 在需要搭建或修改时接受委托：从自然语言目标出发，自主选择器材、设计位置与朝向、运行真实追迹、比较参数并修正方案，不以固定案例匹配。支持当前已实现器件的多透镜、空间折转和分光组合。普通问答不委托搭建；已有装置够用时直接使用。目标判据由 AI 根据用户要求建立，程序计算到屏功率、光斑、落点、器件参数等并逐项核对；AI 对目标的理解仍需用户查看。编辑方案应用前独立复算，未达标、连接中断或等待时装置已变化均不覆盖当前装置。成功后整次搭建可一次撤销，保存存档仍使用“保存装置”。进度来自实际执行步骤，详细说明和核对过程按需展开。高斯场景助手的提示、工具和对话保持独立。

“保存装置”更新当前打开的存档，新的装置在首次保存时建立条目；需要保留两个版本时，通过导入导出菜单“另存为副本”。正在输入的有效数值会在保存时提交，刷新后仍会关联同一份存档；旧的同名存档保留，并显示保存时间。打开或导入装置会自动计算和显示光线；功率为零、关闭光线显示或光线未到达观察屏时，画布给出简短原因。

选中器件后，右侧“一键对齐光轴”将器件中心投影到入射光轴并调整朝向，保持沿轴距离。光源朝向最近的器件；折转镜朝向依据后续器件中心恢复反射方向。蓝色虚线显示光轴基准，参考光轴计算排除所选器件，因此不会随着它被误拖而移动。拖动进入光轴6 mm以内或旋转进入对齐朝向2°以内时自动吸附；可关闭吸附进行精细偏移。数值输入保留用户填写的精确位置；棱镜对齐保留已设计的朝向，只移动中心位置。基准线只辅助搭建，实际光路与功率仍由后台计算。

“实验探究工作区”可选入三维装置并开展仿真与参数比较；聚焦搜索与位置/焦距误差分析仍仅适用于兼容的同轴高斯单透镜装置。需要这些分析时，可先在光路搭建选择“单透镜聚焦”，保存后从实验探究区选入。这些功能不会作为场景库内的课节入口出现。

旧版学习记录仍保留在浏览器中，有记录时可从搭建区“使用帮助”导出备份。场景导航不读取上次课节，也不会覆盖旧学习记录。历史记录校验与报告生成代码仅用于兼容旧数据。当前没有独立的器件资料库。光路搭建已支持空间几何光线与理想高斯光束，不支持真实镜头曲面计算。

## 误差分析使用

打开[本地平台](http://127.0.0.1:5173)，先在“光路搭建”加载并保存“单透镜聚焦”，进入“实验探究工作区”选入该装置，在中间对话中发送明确的误差幅度与研究要求。例如：

> 分析当前方案：透镜位置允许偏差±1 mm，焦距允许偏差±1%，屏上光斑会怎样变化？

要寻找偏差出现后光斑仍较小的方案，可以在该标签选择“寻找较稳定方案”，设置固定屏和参数范围；或发送：

> 观察屏固定在350 mm，标称透镜位置在200–300 mm、标称焦距在80–160 mm之间。位置允许偏差±1 mm，焦距允许偏差±1%。帮我找偏差出现后屏上光斑仍较小的方案，先比较，不要载入。

“标称”就是没有偏差时设定的参数。位置偏差直接加到位置上；焦距偏差按标称焦距的百分比计算。例如焦距100 mm、偏差±1%时，实际焦距范围为99–101 mm。每个非零偏差取9个等间距值，包含端点和零，两种偏差同时组合为81组；只有一种非零偏差则为9组。当前支持位置偏差0–20 mm、焦距偏差0–20%，至少一个非零。允许偏差由你输入，助手不能代替实际测量或自行编造制造精度。

稳定搜索比较21×21个标称参数组合，再在较好点附近细化21×21个；两种偏差非零时，882个候选共评估71442个偏差组合，可能包含重复点。实际偏差可以超出标称搜索范围，不会缩小偏差来制造更好的结果；元件相撞、越界、截光及近轴警告都会记录。只有所有已算偏差组合均通过模型检查的候选才参与推荐；没有合适候选时明确说明原因。目标是减小**最大采样半径**，不是只减小无偏差时的光斑或相对增幅。

早期直线示例（532 nm、束腰半径1 mm、光源30 mm、透镜口径25.4 mm）中，透镜位置250 mm、焦距100 mm在上述误差下的最大采样半径约0.0264305 mm；推荐位置254 mm、焦距96 mm约0.0263212 mm，相对减小约0.41%。无偏差时光斑较小的候选为位置270 mm、焦距80 mm，其最大采样半径约0.0264650 mm。这个例子的稳定性改善较小；当前三维预设的参数不同，不应直接套用这些读数。

打开误差分析记录可查看各偏差下的屏上半径，下拉框切换原方案及可用推荐方案。搜索和分析不修改装置；点击“在光路搭建中查看推荐”才打开推荐参数副本，可在搭建区撤销这次载入。取消或失败不会加载中间方案。

分析JSON保存原装置、误差与目标设置、算法版本、全部候选摘要，以及当前、标称较小和稳定推荐三种方案的完整偏差表。CSV包含同样的设置与单位、候选摘要和这三份偏差表（双偏差时共243行），不包含所有71442行中间数据。使用导出的 `inputSnapshot`、`tolerance`、`mode`、`goal` 向 `POST /api/research/tolerance` 发送请求，另加任意 `requestId`，即可复算全部候选。记录编号和时间会重新生成。分析记录随研究自动保存，也可单独导出；分析JSON不能当作装置文件导入。

这是理想薄透镜、高斯光束模型中的有限采样比较，不能保证连续误差范围的严格最坏值，也没有设置发生概率、95%置信度或真实实验标定。包含误差分析的助手回复使用程序核对摘要；其他普通解释仍可能有误，需结合计算数据和模型限制判断。

## 参数搜索使用

打开[本地平台](http://127.0.0.1:5173)，先在“光路搭建”加载并保存“单透镜聚焦”，在“实验探究工作区”选入该装置并设为当前，在中间对话中发送：

> 观察屏固定在350 mm，透镜位置可在200–300 mm之间，焦距可在80–160 mm之间，帮我找到屏上光斑较小的方案。

Agent实际调用搜索后，图表保存在实验记录中。搜索不会修改装置；点击“在光路搭建中查看推荐”才打开推荐参数副本，包括目标屏的固定位置。光源的波长、束腰、功率、采样设置及其他屏保持不变。当前有多片透镜时，需要先准备兼容的单透镜装置；不会静默删除原装置中的透镜。

早期直线示例（532 nm、输入束腰半径1 mm、光源刻度30 mm、透镜直径25.4 mm）的上述范围会推荐透镜刻度270 mm、焦距80 mm，屏上半径约0.013547 mm，比原透镜刻度250 mm、焦距100 mm在同一个350 mm屏上的半径减小20%。这是理想模型下已计算网格点中的较好方案，焦距落在范围下边界，不是连续范围或全局最优的保证。当前三维预设参数不同，实际读数以对应研究记录为准。

搜索先比较441组全范围等间距组合，再在无警告的较好组合附近细化441组。两阶段可能有重复组合，计数表示计算次数。若全范围没有任何通过模型检查的组合，则保留441组参考或错误结果，不生成推荐。截光或近轴警告的组合可查看，但不参与推荐。基线使用原透镜位置、焦距及同一个目标屏位置；原透镜参数可能在搜索范围外。比较目标始终是**指定屏上的半径**，不是传播全程最小半径。

搜索始终使用本轮研究对象的参数副本，其他模块的后续修改不会改写本轮记录。停止等待不加载方案。设计记录与对话一起保存在当前浏览器，可导出备份。需要按最新装置继续研究时，先更新研究对象的参数，再重新计算。

导出的设计JSON包含 `inputSnapshot` 和 `goal`，使用这两个字段向 `POST /api/research/focus` 发送请求（另加任意 `requestId`）即可重新计算。在相同物理模型与搜索版本下，各计算行和推荐可复现；记录编号和时间每次重新生成。设计记录不能直接当作装置文件导入，备份装置请使用“导出装置”。

## 配置AI接口

项目提供 `.env.example` 配置样例。本机 `.env` 中填写支持 Chat Completions 和工具调用的模型服务：

```dotenv
AI_BASE_URL=https://你的服务地址/v1
AI_MODEL=你的模型名称
AI_API_KEY=你的API_Key
```

接口地址使用服务商提供的基础地址，后台会在末尾添加 `/chat/completions`。模型名称由你填写，不限制品牌。原有本机配置继续兼容；改用通用配置时应填齐这三项。配置每次请求重新读取，系统环境变量优先于 `.env`。

使用官方 DeepSeek 接口时默认开启思考。实验探究工作区默认为 `high`，可通过 `.env` 中的 `AI_RESEARCH_REASONING_EFFORT` 单独设置；其他模块沿用 `AI_REASONING_EFFORT`，默认 `high`。两项设置均支持 `low`、`high`、`max`，设为 `none` 关闭思考；也适用于原有本机接口配置，不向其他服务商发送专属参数。普通思考模式的生成额度为32768 tokens，`max` 为131072 tokens（包含思考与最终回复）。普通思考模式单次请求读超时120秒、整轮处理预算300秒；`max` 分别为240秒与600秒，搭建时为返回实验探究工作区继续计算预留120秒预算。科研网页最长等待630秒，用户仍可随时停止；其他页面沿用原等待时间。额度是上限，回复仍按简短教学说明生成。本轮连续工具调用和核对前接续保留必要思考上下文，只用于后台请求，不返回网页、对话存储或导出文件。浏览器历史仅用于恢复可见问答，每个新问题重新开始思考。

界面只显示“AI助手”，不展示服务商或模型名称。API Key只由后台读取，不会发送给浏览器或写入实验文件。请求发送到你配置的模型服务，费用按其规则收取。

实验探究助手 可直接调用已有的光波叠加、杨氏双缝、迈克耳孙及薄膜干涉模型，计算并扫描相位、振幅、光程等参数。结果在实验探究工作区显示，模型参数和扫描记录独立保存，后续追问可继续计算；不需要预先生成三维几何装置。此接入复用原有物理计算，不把局部相对光强当作绝对功率，也不代表任意三维光路的相干叠加或全局能量去向已得到验证。

普通知识问题直接讲解，不强制计算或代入当前参数。要求计算、比较或修改装置时，助手才按需调用工具；修改方案在应用前必须通过实际计算，仍可一次撤销。公式使用数学排版，比较数据由独立表格显示。

高斯光束助手支持按目标光斑半径反求束腰，例如“把观察处光斑半径调到0.4 mm，其他参数保持不变”。求解固定发送时的波长、束腰位置和观察位置，在0.01–20 mm的束腰范围内求出所有解，并用同一仿真程序逐个核对。有两个解时默认选择与当前束腰改动较小的一个，也可明确要求较大或较小束腰。只问“能否达到”或“需要多大束腰”会给出解而不改参数；明确要求调到目标才应用，仍可在回复旁撤销。不可达目标会说明当前条件下的范围，保留原参数。半径和直径必须分清，目标未给数值、单位或定义时会追问。

数值、单位和操作对象明确的“调到目标光斑”或“将束腰半径调整为某个值”直接由后台执行并核对，不依赖模型再次决定是否应用；指定束腰数值时不会重复上一轮光斑目标的求解。询问、假设和明确要求不修改时，计算工具不得写回参数。复杂或条件不全的请求继续交给助手解释或追问。

高斯场景与科研助手按原方式分别保存对话和输入草稿，最多保留最近40轮。三维搭建 Agent 使用另外的对话存储，持久保存最近12条消息（总计不超过24000字符），关闭和重新打开可恢复文字与实际载入状态；详细计算证据和回复旁的撤回只在当前会话保留。未完成的问题在失败或点击停止后恢复到输入框。清空对话只删除对应助手的历史，重要计算记录仍应单独导出。

每轮最多8次模型请求、16次工具步骤，处理时限约120秒；失败不应用中间方案。等待期间手动修改参数时，旧方案不会覆盖当前装置。关闭高斯助手不会中断正在进行的问答；离开场景或刷新可能中断未完成请求，问题仍会保留并提示重新发送。

## 计算范围与结果解释

支持0–600 mm同轴位置，最多50个元件和一个光源。计算方向为光源向右；重合元件或位于光源左侧的元件会得到明确提示。

模型采用空气中的理想薄透镜与近轴传播。“近轴”指光线与光轴夹角较小；当前不计算真实曲面、像差、偏振、复杂光场或物体成像。3D镜片外形为示意，不由焦距推导。

高斯光束的光强从中心向外平滑降低。当前采用理想基模，光源所在平面为束腰，也就是输入光束最细的位置；半径定义为光强降至峰值约13.5%的距离。几何光线在光源处初始平行，不含高斯光束的衍射发散，因此光线交点与高斯光束最细的位置不必相同。最小半径使用各传播段的解析极值求得，不依赖粗采样碰巧落在焦点。

观察屏是**不遮挡后续传播的采样平面**。光强按每个屏自身峰值归一化，中心值为1；未设置激光功率，没有绝对功率单位。屏内功率比例和峰值相对光源的比例都是理想未截断光束的结果。

透镜口径用于遮挡几何光线，并评估高斯光束截光比例。预计截光超过1%，或近轴斜率/高斯发散半角超过0.1时，页面显示“仅作参考”和具体原因。当前没有计算有限口径截断后的衍射场，这些阈值也不是与真实实验一致的误差保证。

3D画面调整光束与光斑的横向显示倍率，并明确标注倍率。曲线、光斑坐标与导出数据始终使用实际毫米。光斑图自动放大局部区域，横纵范围显示在图下；比较不同观察屏时需同时看半径数值，不能只比较图上亮斑的大小。

计算长度使用毫米，波长从纳米换算为毫米。高斯传播采用 `q = z + i zR` 的符号约定，自由传播为 `q_out = q_in + d`，薄透镜为 `1/q_out = 1/q_in − 1/f`。公式依据：[MIT高斯光束课程资料](https://ocw.mit.edu/courses/6-974-fundamentals-of-photonics-quantum-electronics-spring-2006/e9852c138493233bc2813f683da5b199_gaussian_bem_res.pdf)及[MIT几何光学课程资料](https://ocw.mit.edu/courses/2-71-optics-spring-2014/04d4bff4ff4a9ae5e2c8ba7500905557_MIT2_71S14_lec4_notes.pdf)。

## 保存说明

草稿与实验库保存在当前浏览器的本地存储。换浏览器、换端口、清理浏览器数据都可能使其不可见。重要实验请**导出JSON文件备份**。加载模板、导入文件和载入存档均可撤销。撤销记录仅保留本次会话最近80次编辑，操作记录也仅保留本次会话。最多保存40份独立存档，实验文件最多1 MB。

“结果JSON”包含当前装置完整参数与计算结果，“CSV”包含参数记录、传播半径数据和观察屏摘要。它们用于分析和复现；装置导入读取的是“导出装置”生成的文件，结果JSON不能直接作为装置文件导入。第一阶段装置文件仍可读取，已有装置位置不会被新模板自动改写。刷新后用恢复的参数重新计算。

参数比较保存当前装置快照、扫描参数、全部采样点及读数，回复内可展开表格。比较任务可核对读数的变化幅度、单调不减或单调不增趋势；不能把“不满足不减”当作“不增”。观测对象使用观察屏或功率计编号，与被扫描的器件编号分开。改变其他实验条件会使旧比较依据失效；选择同一扫描参数的数值则保留比较依据。达到模型轮次或时间上限时，程序独立核对已完成方案；只有目标真实通过才允许载入，不会仅因缺少最后一句模型回复丢弃有效工作。未达标与追迹截断仍禁止载入，失败时保留可展开的本轮执行记录。
